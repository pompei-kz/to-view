# Перенос движка to-view на Rust

Исходный запрос — [01-prompt-rust-player.txt](01-prompt-rust-player.txt).

## Целевая архитектура

Rust владеет основным циклом, потоками, очередями, часами, состоянием воспроизведения, перемоткой, меню и жизненным циклом окна. FFmpeg остаётся статической библиотекой для чтения контейнеров, декодирования и преобразования видео и звука. SDL2 остаётся статической библиотекой для окна, ввода, вывода кадров и аудио. В релизе отсутствуют код и патчи `fftools`, входная точка `to_view_ffplay_main` и запуск внешних программ.

## Этапы

1. **Зафиксировать текущее поведение.** Составить список поддерживаемых контейнеров, кодеков, CLI-опций и реально работающих клавиш. Подготовить воспроизводимые локальные образцы с видео без звука, с A/V, с длинным GOP, с ненулевым стартовым временем, без известной длительности и с повреждённым контейнером. Зафиксировать поведение паузы и перемотки на границах, естественного конца и явного перехода на последний кадр. Сравнивать новый движок с текущим бинарником из Git.
2. **Подготовить статическую сборку библиотек и Rust FFI.** Собирать зафиксированные версии FFmpeg и SDL2 из уже загружаемых исходников. Для FFmpeg собирать только используемые архивы `libavformat`, `libavcodec`, `libavutil`, `libswscale` и `libswresample`. Оставить `libavfilter`, если он требуется для подтверждённого поведения текущего плеера. Сгенерировать FFmpeg-привязки из заголовков той же версии и изолировать `unsafe` в небольшом модуле с RAII-обёртками для контекстов, пакетов и кадров. Проверить статическую линковку и доступность build-time-инструментов для генерации привязок на чистой системе.
3. **Сделать запуск видео полностью из Rust.** Передавать типизированный `player::Options` напрямую движку. Открывать локальный файл через `libavformat`, выбирать потоки, декодировать через `avcodec_send_packet` и `avcodec_receive_frame`. Передавать кадры в SDL2 с учётом формата, stride и пропорций видео, используя `libswscale` при необходимости. Управлять SDL2 из основного потока. Чтение и декодирование выполнять вне цикла интерфейса, использовать ограниченные очереди и отменяемое ожидание, чтобы пауза и закрытие не блокировали окно.
4. **Подключить звук и синхронизацию.** Приводить звук к формату SDL2 через `libswresample`, ограничить буфер и сделать подачу аудио независимой от файлового ввода. При доступном звуке рассчитывать часы по фактически воспроизведённому аудио с учётом очереди и задержки устройства. Для видео без звука использовать монотонные часы. Нормализовать PTS и стартовое смещение потока, замораживать часы на паузе, корректно дренировать декодеры и аудиобуфер в конце. Проверить, что при медленной декодировке плеер сохраняет синхронизацию и отзывчивость.
5. **Перенести перемотку и крайние состояния.** Запрашивать предшествующий ключевой кадр через библиотеку FFmpeg, сбрасывать декодеры, ресемплер и очереди, отбрасывать предролл до целевого времени. Привязывать пакеты, кадры и звук к поколению перемотки, чтобы устаревшие данные не могли появиться после быстрого повторного ввода. Сохранить паузу, шаги 1/5/30 секунд, Home/End и остановку на крайних кадрах без перехода по кругу. Проверить отдельные сценарии для видео, которое заканчивается раньше аудио, и контейнеров без точного индекса. Обработать неизвестную длительность явно. Для естественного конца сохранить `--close-on-end` и все короткие формы.
6. **Перенести окно и меню.** Создавать окно и ставить иконку напрямую из Rust через SDL2. Заменить передачу геометрии аргументами ffplay на типизированную загрузку и сохранение с прежними путями и форматом. Перенести Esc, физическую Q/Й, паузу, полноэкранный режим и поддерживаемые сочетания. В Rust отрисовать seekbar по [утверждённому плану](../001-seekbar/09-PLAN-seekbar.md), включая предпросмотр, прозрачность штрихов и порядок слоёв. Закрывать окно и освобождать ресурсы через обычный выход из цикла Rust.
7. **Переключить релиз и убрать старую сборку.** После прохождения проверок заменить текущий вызов ffplay новым движком. Удалить сборку объектов `fftools`, `libffplay.a`, переименование `main`, все патчи FFplay, `ffplay-seekbar.h` и оставшиеся мосты, относящиеся только к ffplay. Сохранить `make` и `cargo build --release` как штатные команды сборки.

## Критерии приёмки

- Из чистого дерева собирается единый `target/release/to-view`. Проверка `readelf -l -d` не показывает `INTERP` и `NEEDED`. Запуск с пустым `PATH` воспроизводит тестовое видео. Трассировка плеера не показывает загрузки `.so` или запуска дочерних программ.
- Релиз не компилирует и не линкует `fftools`. Rust управляет воспроизведением и интерфейсом через библиотечные API.
- Проверены воспроизведение со звуком и без него, синхронизация, повторные перемотки, пауза, первый и последний кадры, естественный конец, повреждённый файл и закрытие во время загрузки или перемотки. Проверки окна включают меню, полноэкранный режим и восстановление геометрии между запусками.
