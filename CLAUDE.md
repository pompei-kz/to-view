# Правила to-view

- Исполняемый файл to-view должен работать без установленных внешних библиотек времени выполнения. Связывай Rust, FFmpeg, SDL2, системную C-библиотеку и остальные нативные зависимости статически. Не загружай разделяемые библиотеки во время работы и не запускай внешние программы для воспроизведения.
- Собирай приложение через Cargo. Нативные исходники и сборочные артефакты держи в каталоге сборки. Фиксируй версии и контрольные суммы загружаемых исходников.
- Сохраняй запуск `to-view /path/to/video.mp4` с немедленным воспроизведением. Разбирай новые опции в Rust и передавай настройки плееру через `player::Options`.
- После изменений сборки проверь релизный ELF через `readelf -l -d target/release/to-view`. В нём не должно быть интерпретатора `INTERP` и записей `NEEDED`.
